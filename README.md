# AI Interview Preparation Platform

An AI-powered full-stack interview preparation platform built using React, Spring Boot, MySQL, JWT Authentication, and Ollama LLM.

This platform helps students prepare for:
- Technical Interviews
- HR Interviews
- Coding Rounds
- Resume Screening
- Company-Specific Placements

---

# Features

## Authentication System
- User Registration
- Secure Login
- JWT Authentication
- Protected Routes

- Voice-based interview support

# Installation & Setup

## Clone Repository

```bash
git clone https://github.com/sujal-09/ai-interview-preparation-system.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## Backend Setup

```bash
cd backend
mvn spring-boot:run
```

---

## Run Ollama

```bash
ollama run llama3
```
